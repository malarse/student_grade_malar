# Student Grade Manager

## Project Overview
A simple Python application to manage student details and calculate grades based on marks.

## Features
- Add student details
- Enter student marks
- Calculate grades
- Display student results
- Handle invalid inputs

## Technologies Used
- Python 3
- Functions
- Conditional Statements
- Exception Handling

## How to Run

Open the terminal and execute:

python test2.py
